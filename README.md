CodeOrbit Tech AI Internship Projects
Project Introduction

This repository contains the completed tasks for the CodeOrbit Tech Artificial Intelligence Internship (1-Month Tier). It demonstrates foundational AI concepts including deterministic natural language processing, algorithmic game theory, and applied computer vision.

Project Overview and Features
Task 1: Rule-Based Chatbot: A conversational agent that uses keyword matching and predefined rules to route user queries and provide information about the internship.

Task 2: Tic-Tac-Toe with Minimax AI: A command-line Tic-Tac-Toe game featuring an unbeatable AI opponent powered by the Minimax algorithm with Alpha-Beta pruning.

Task 3: Pretrained Image Classification: A computer vision script utilizing PyTorch and the MobileNetV2 architecture to classify sample images into 1,000 distinct ImageNet categories.

Tech Stack
Python 3.x

PyTorch & Torchvision (Deep Learning Inference)

Pillow (Image Processing)

Getting Started: Setup and Running Instructions
Clone this repository to your local machine.

Install the required dependencies by running: pip install -r requirements.txt

Execute any of the individual task scripts using Python (e.g., python task1_chatbot.py).

For Task 3, ensure you place a valid image named sample_image.jpg in the root directory before running.
